CarMirror for Android

Download the APK

One-time setup on the phone

  1. Install Shizuku from Google Play (or GitHub: RikkaApps/Shizuku).
  2. Start Shizuku with Wireless debugging. Shizuku's own screen walks you through it: Developer options → Wireless debugging → pair with code. After a phone reboot, open Shizuku and tap Start again.
  3. Install the CarMirror APK (allow "install unknown apps" for your browser or file manager).
  4. Open CarMirror, tap Grant Shizuku access, pick the apps to show in the car, then tap Start.

In the car

  1. Turn on the phone's hotspot and connect the car to it (car Wi-Fi settings).
  2. Open the car's browser at carmirror.outsmartis.dev and type the 6-digit code shown in the phone app. You only pair once.
