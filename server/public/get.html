New here? What CarMirror is and how it works.

On the phone (once)

  1. Install the APK. Your browser will ask to allow installing apps from it.
  2. Open CarMirror and turn on Touch from the car (Accessibility). If the switch is greyed out: App info → ⋮ → Allow restricted settings.
  3. Allow Display over other apps.
  4. Pick the apps to show in the car.
  5. Optional: Shizuku for car-sized app screens and split view.

In the car

  1. Phone hotspot on, car connected to it.
  2. Car browser: carmirror.outsmartis.dev, then type the code from the phone app (first time only).

Updating? Install the new APK over the old one: pairing and settings are kept.
